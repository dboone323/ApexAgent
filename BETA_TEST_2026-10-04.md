## LAUNCH BLOCKERS (must fix before public use)

1. **Settings gear click terminates the app.** Repro: click the toolbar gear icon → app vanishes and relaunches. Observed once; deliberately not re-clicked. Daniel to confirm via Xcode crash log. The app's ONLY settings entry point (no Settings… menu item) kills the app.
2. **Help → Apex Agent Help is a dead end.** Repro: Help menu → Apex Agent Help → window reading "Help isn't available for Apex Agent." Ship real help content or remove the menu item.
3. **No Settings… item in the app menu.** Standard macOS convention; the only settings access is the gear button that crashes (blocker 1). Both must be fixed together.
4. **Create Bot pre-fills Bot Name with an existing bot's name.** Repro: Bots → New Bot → name field contains "Luna Helper" (an existing bot). Stale default — invites accidental duplicate/confusing bot identities. Should be empty with a placeholder.
5. **Routines have no reachable UI.** No way to create, save, toggle, or Run Now a routine from anywhere in the app (checked all menus, sidebar, context menus). If Routines ship, this is a blocker; if not shipping, remove from docs.
6. **No way to run a Playbook from the UI.** Only import/export exist. If playbooks are a user-facing feature, there must be a run path (and the approval-card flow needs to be reachable); otherwise descope.
7. **Pages cannot be deleted.** No context menu, no delete button, clicking the page does nothing. The "Beta Test Page" created during this test cannot be removed. Every user-created object needs a delete path.
8. **File > New Conversation has no visible effect.** Menu action dispatches; nothing changes in the UI. Either broken or its effect is invisible — both are wrong for a shipping menu item.
9. **Compose toolbar button has no visible effect.** Clicked; nothing changes. Its purpose is undiscoverable — wire it up or remove it.
10. **Delete Bot flow untested.** Daniel clicked Cancel on the "Delete Bot?" modal, so the Delete path was never exercised — the dialog itself renders correctly, but whether Delete actually deletes is unknown. Retest needed.
