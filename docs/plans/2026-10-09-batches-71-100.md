# Autonomous Hardening Roadmap (Batches 71–100: Loops 10, 11 & 12)

## Executive Summary
This document establishes the comprehensive plan to complete autonomous hardening across the entire ApexAgent and SharedKit codebase, spanning Batches 71 through 100 across three final 10-batch loops (Loops 10, 11, and 12). 

Every batch adheres to the strict user rule:
- **100% Real Functional Code & Real Validation Tests**: Zero mocks, stubs, placeholders, or dummy assertions.
- **Atomic Conventional Commits**: Individual commit per batch.
- **Hygiene & Lint Zero-Tolerance**: `make hygiene` (secrets, forbidden names, raw prints, plist/entitlements parity, supply-chain pins) and `make lint`.
- **Targeted Test Verification**: Full `xcodebuild test` verification before PR creation.

## Detailed Specification: Loop 10 (Batches 71–80)

### Batch 71: Discord Gateway & Webhook Security Auditor
- **Production File**: `ApexAgent/Security/DiscordWebhookSecurityAuditor.swift`
- **Test File**: `ApexAgentTests/DiscordWebhookSecurityAuditorTests.swift`
- **Focus**: Ed25519 signature verification algorithm, HMAC-SHA256 timestamp replay protection (reject requests > 300s old), message length bounds (2000 chars), mention stripping (`@everyone`, `@here`), rate-limit header parsing (`X-RateLimit-Remaining`, `X-RateLimit-Reset`).

### Batch 72: Keychain Manager Attribute & Secure Memory Zeroing Gate
- **Production File**: `ApexAgent/Security/KeychainIntegrityAuditor.swift`
- **Test File**: `ApexAgentTests/KeychainIntegrityAuditorTests.swift`
- **Focus**: Verify accessibility attribute `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`, prevent iCloud Keychain synchronization for local agent credentials, enforce cryptographic key entropy (minimum 256 bits), secure byte buffer zeroing after secret extraction to prevent heap memory dumps.

### Batch 73: Full Duplex Voice Session VAD & Audio Timing Gate
- **Production File**: `ApexAgent/Models/VoiceSessionAudioAuditor.swift`
- **Test File**: `ApexAgentTests/VoiceSessionAudioAuditorTests.swift`
- **Focus**: Audio frame boundary validation, Voice Activity Detection (VAD) energy thresholding (`dBFS` calculation from linear PCM), sample rate conversion verification (16kHz / 24kHz / 48kHz mono 16-bit PCM), audio packet jitter buffer sequencing.

### Batch 74: Interactive PTY Terminal ANSI Escape Sanitizer Gate
- **Production File**: `ApexAgent/Security/TerminalSecurityGate.swift`
- **Test File**: `ApexAgentTests/TerminalSecurityGateTests.swift`
- **Focus**: ANSI sequence parser for PTY sessions (`PTYSession`, `ANSIColorParser`), strip dangerous OSC escape codes (e.g. `OSC 52` clipboard manipulation, `OSC 0` window title hijacking), validate cursor coordinate movement within terminal bounds, truncate oversized scrollback buffers.

### Batch 75: Collaborative Spaces & AppGroup Shared Bus Gate
- **Production File**: `ApexAgent/Security/SpaceSecurityAuditor.swift`
- **Test File**: `ApexAgentTests/SpaceSecurityAuditorTests.swift`
- **Focus**: Multi-agent shared space access control, AppGroup directory path isolation (`group.com.apexagent`), distributed file lock lease expiration verification (reclaim stale locks > 30s), participant role permission matrix (`admin`, `editor`, `viewer`).

### Batch 76: Routine Recorder Deterministic Event Replay Gate
- **Production File**: `ApexAgent/Models/RoutineReplayAuditor.swift`
- **Test File**: `ApexAgentTests/RoutineReplayAuditorTests.swift`
- **Focus**: Event recording sequence validator, step idempotency enforcement, parameter substitution sanitization, pre-condition and post-condition assertion verification before and after step execution.

### Batch 77: Virtual Display & Screen Streamer FPS & Memory Gate
- **Production File**: `ApexAgent/Tools/ScreenStreamerResilienceAuditor.swift`
- **Test File**: `ApexAgentTests/ScreenStreamerResilienceAuditorTests.swift`
- **Focus**: Display resolution limits (max 4K `3840x2160`), FPS throttling (cap at 60 FPS, adapt to 15 FPS under memory pressure), pixel format validation (`kCVPixelFormatType_32BGRA`), frame buffer allocation budget caps to prevent OOM.

### Batch 78: Multi-Agent Debate Consensus & Byzantine Quorum Gate
- **Production File**: `ApexAgent/Coordinators/DebateConsensusAuditor.swift`
- **Test File**: `ApexAgentTests/DebateConsensusAuditorTests.swift`
- **Focus**: Majority and supermajority quorum calculation (e.g., $2f + 1$ validation), detection of uncooperative or contradictory agent propositions, debate round ceiling enforcement, final synthesis confidence score auditing.

### Batch 79: Speculative Tool Execution DAG & Transaction Rollback Gate
- **Production File**: `ApexAgent/Tools/SpeculativeExecutionAuditor.swift`
- **Test File**: `ApexAgentTests/SpeculativeExecutionAuditorTests.swift`
- **Focus**: Directed Acyclic Graph (DAG) cycle detection for speculative tool calls, transactional state snapshots, automated rollback step execution (`FileRollback`) upon speculative step failure, isolation of uncommitted mutations.

### Batch 80: LaunchAgent Plist & Socket Activation Lifecycle Gate
- **Production File**: `ApexAgent/Models/LaunchAgentLifecycleAuditor.swift`
- **Test File**: `ApexAgentTests/LaunchAgentLifecycleAuditorTests.swift`
- **Focus**: Audit launchd daemon property list dictionary (`Label`, `ProgramArguments`, `RunAtLoad`, `KeepAlive`, `StandardOutPath`, `StandardErrorPath`), socket activation descriptor validation, graceful shutdown timeout verification (SIGTERM -> SIGKILL escalation).
