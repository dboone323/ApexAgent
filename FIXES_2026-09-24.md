## 2. What got fixed (by workstream)

### Workstream 1 — Security
- **C1** `ApexAgent/Models/KeychainManager.swift`: removed the `secure.<key>` UserDefaults mirror; `save` returns the real Keychain result (no more forced success); `get`/`delete` no longer touch plaintext. One-time lazy migration moves existing `secure.*` defaults into the Keychain and deletes the plaintext copy only after a successful write. In-memory fallback stays non-persisted; audit records log key names/status only, never values.
- **C2** `ApexAgent/Models/ApexGatewayServer.swift` (+ `GatewayModels.swift`, `ApexGatewayClient.swift`): listener bound to 127.0.0.1 only (`requiredLocalEndpoint`); 32-byte pre-shared token generated once, stored in Keychain (`apex.gatewayToken`), printed once on first launch; new `GatewayAction.authenticate(token:)` handled first — no other action honored until the token matches (wrong/empty token closes the connection). Frame body capped at 8 MiB. Client sends `.authenticate` immediately on connect.
- **H2** `ApexAgent/Security/AgentSecurity.swift`: `execute_dynamic_tool` moved from `.medium` to `.high` — now requires human confirmation.
- **H3** `ApexAgent/Models/MCPClient.swift`: `executeDynamicScript` validates the path (expands `~`, resolves symlinks, must exist, be a regular file, and live under resolved `~/.apex/tools` or `~/.apex/skills` — new `DynamicScriptError.invalidPath`); bounded execution with `timeout` (default 60s), SIGTERM → 2s grace → SIGKILL → reaped (`killProcess`); expiry/cancellation kills the child (no leaks). New public error cases with safe descriptions (no secrets).
- **H4** `ApexAgent/AgentOrchestrator.swift`: deleted the six runtime test-detection heuristics in `requestConfirmation`; auto-approve now gated strictly behind `#if DEBUG`. Full scan confirmed no other env heuristic disables confirmation. Stale comment updated.
- **H5** `ApexAgent/Models/AgentRegistry.swift`: replaced `nonisolated(unsafe)` dictionary with a Mutex-guarded `AgentStore` (`@unchecked Sendable`); `init`/`allAgents`/`resolve`/`register`/`unregister`/`loadAgentsFromDisk` all go through it. Public API stays synchronous — no call-site changes.
- **M1** `ApexAgent/Models/CollaborativeServer.swift`: `apex.collabToken` moved to Keychain with legacy migration (delete-after-successful-save); `isAuthorized`/`hasPermission` read the Keychain.
- **M2** `ApexAgent/Models/WebhookServer.swift`: `requiredLocalEndpoint = 127.0.0.1` set before listener construction.
